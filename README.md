
# Assignment 2 - Personal Portfolio

This is my personal portfolio website created for my Web and Scripting course.

The website was built using Node.js, Express.js, EJS, HTML, CSS, and Bootstrap.

## Pages

- Home - A short introduction about me.
- About Me - Information about my background and an introduction video.
- Projects - Some of the projects and labs I have completed.
- Contact Me - A contact form where visitors can submit a message.

## Running the Website

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000` in a browser.
